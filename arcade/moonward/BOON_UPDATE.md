# 보스 축복 선택 · 2026-10-24

6·12웨이브에서 보스를 실제 처치하고 웨이브 방어를 완료하면 세 축복 중 하나를 선택한다. 보스가 성문을 통과하면 선택 보상을 주지 않는다. 18웨이브는 바로 승리로 끝난다.

| 축복 | 효과 / 한 번 선택 기준 |
|---|---|
| 깊은 가시 | 독 피해 +10%, 지속 +1초 |
| 서리 추격 | 둔화 중인 적에게 궁수 피해 +25% |
| 달빛 보급 | 즉시 125 조각, 성문 3 회복(최대 20) |

같은 축복을 다시 고르면 효과를 더한다. 공격 보너스를 곱연산으로 중첩하지 않는다. 해당 판의 새 소환·합성 유닛에도 적용하고 새 판에서는 초기화한다. 갑각·보스의 궁수 피해 감소는 유지한다.

선택 카드에는 관련 유닛 보유 수 또는 지급 후 재화를 표시한다. 카드를 누르면 세부 효과와 누적 효과를 확인하고 별도 확정 버튼으로 적용한다. 선택 중 엔진 시간이 멈춘다. 작전 화면과 결과 화면에서 이번 판의 선택을 다시 확인할 수 있다. 작은 화면은 카드/설명만 스크롤하고 확정 버튼은 별도 영역에 둔다.

## 저장과 검증

기존 `firemate_moonward_v1` 키와 버전 유지. `boons`, `pendingBoon`, `bossDefeated`를 선택 필드로 추가하며, 구 저장은 기본값으로 복구한다. 과거 보스 보상은 소급 지급하지 않는다. 선택 대기와 확정 직후를 저장하고, 이벤트 재실행·연속 클릭·재접속으로 중복 지급되지 않게 엔진에서 검사한다.

- 엔진/피드백/축복 테스트 총 22개 통과. 실제 처치와 누출 구분, 6/12/18 분기, 선택 중 시간 정지, 구 저장, 중복 지급, 독과 조건부 궁수 피해, 성문 회복 상한 검증.
- 브라우저 UI 흐름 검사 19개 통과. 선택 전 재접속, 선택·확정, 같은 콜백 두 번 호출, 선택 후 재접속, 초기화, 모바일 카드 선택 및 설명/버튼 겹침 방지 포함.
- 기존 18웨이브 브라우저 엔진 완주·승리·재도전, 320~768px 조작 영역, 100마리 렌더 검사 통과. 100마리 명령 제출 p95 약 0.6ms는 데스크톱 헤드리스 수치이며 실기기 FPS가 아니다.
- 실제 공용 SW를 사용한 온라인→오프라인 재접속·이어하기와 금융 확인용 저장 키 보존 통과.
- check_app, PWA update, storage rollback, calculations, finance 검사 통과.
- 초기 구현 중 저장 인자 오류를 브라우저 검사가 발견하여 수정했다. 작은 화면 확정 버튼 겹침도 캡처 확인 후 수정했다.

## 수치 조정 근거

초기 독 +15% / +2초는 조합 전략 20시드에서 19승, 무작위 전략에서 18승이었다. 최종 +10% / +1초로 줄여 차이를 완화했다. 보급에는 체력이 깎인 상황을 위한 회복 3을 추가했다.

최종 비교: 각 행은 동일한 1~20시드, 3종 배치·구매 전략 × 4종 보상 정책 = 총 240판. '없음'은 비교 실험에서 보상을 선택한 직후 효과를 제거한 기준선이며 실제 게임 선택지가 아니다.

| 단순 전략 | 보상 없음 | 독 강화 | 서리 추격 | 보급 |
|---|---:|---:|---:|---:|
| 역할 혼합 | 14/20 | 18/20 | 17/20 | 15/20 |
| 무작위 소환·합성 | 11/20 | 17/20 | 16/20 | 10/20 |
| 궁수만 | 0/20 | 0/20 | 0/20 | 0/20 |

독 강화가 이 정책들에서는 여전히 유리하다. 보급 정책은 무작위 구매 순서를 바꾸며 완주가 오히려 한 판 감소했다. 재화가 남아도 배치 공간과 조합이 제한되므로 보급의 재화를 충분히 활용하지 못하는 단순 정책의 한계도 있다. 이 결과로 모든 선택의 균형이나 실제 사람의 승률을 보장하지 않는다. 시드별 승패·도달 웨이브·남은 재화·생명은 `tests/evidence/boon-simulation.json`에 기록했다.

## 실행 및 연결

`node --test arcade/moonward/tests/*.test.mjs`
`node arcade/moonward/tests/boon-simulate.mjs --json`
Playwright 환경에서 `MOONWARD_CHROMIUM=/path/to/chromium node arcade/moonward/tests/browser.cjs`.
저장소 루트 `python3 -m http.server 4180` 후 `/arcade/moonward/` 접속.

새 런타임 파일·의존성·리소스 없음. 기존 메뉴 경로와 SW 런타임 캐시로 동작하며 Claude의 금융·공용 파일 변경은 필요 없다. 최종 진화와 보스 패턴 차별화는 이번 범위에 포함하지 않았다. 실제 휴대전화 설치형 PWA, 장시간 사람 플레이와 재미 검증은 미검증이다. 첨부 선택 화면은 검증용 전투 상태에서 실제 게임 UI를 캡처한 것이다.
