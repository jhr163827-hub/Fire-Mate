## 권리와 정확도

- 코드로 작성하는 쿼터뷰 좌표, 터치·배치·저장·시간 흐름은 독립 구현한다.
- 새 SVG 인물/가구/실내는 이 프로젝트에서 직접 작성하는 독립 그래픽이다. 뿌까/가루 등의 원본 그림, 로고, 게임 텍스처, 스프라이트/애니메이션 파일은 앱에 포함하지 않는다.
- 원작과 동일한 캐릭터·가구·UI 스킨이 필요하면 Pucca IP 이용 범위와 MobCrete 게임 리소스의 복제/변형/공개 배포 권한을 확인할 자료가 필요하다. '무료 다운로드', 스크린샷 공개, 개인 비상업 이용 안내만으로 해당 허락을 확인했다고 보지 않는다.
- 일반적인 쿼터뷰·가구 터치·장시간 조리의 흐름은 재현을 진행할 수 있다. 원본 그래픽의 픽셀 일치, 프레임/행동 타이밍, 전체 경제 밸런스 일치는 현재 증명할 수 없다. 근거 없는 재현율 퍼센트를 제시하지 않는다.
- 필요한 추가 증거: 2011 버전 식별 가능한 연속 플레이 영상(조리 완료→서빙→계산, EDIT/상점/회전), 메뉴의 비용/수량/판매가/XP/시간 화면, 직원 고용·확장 요구치, 권리자의 허용 범위 문서.

## 작은 구현 순서

1. **이번 단위**: 독립 그래픽의 쿼터뷰, 실제 조리 상태와 연결된 장면 조리대, 가구 이동·배치 저장·취소, 모바일 모달 뒤로가기. 기존 경제/진행 기록 유지.
2. **후속**: 증거 확보 후 조리 배치→서빙대 재고→직원/손님→계산을 분리. 기존 jobs를 새 모델로 바꿀 때 보존 마이그레이션 설계부터 검증.
3. **후속**: 확인된 XP/레벨·고용·상점·확장/회전·숙련·폐기 규칙. 원작 수치 미확인 영역은 자체 수치를 원작이라 부르지 않음.
4. **권리 확인 후**: 허용된 원작 캐릭터/그래픽·프레임 적용. 음악/효과음 제외.
