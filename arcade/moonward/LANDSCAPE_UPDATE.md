# 가로 화면과 역할 전달 개선

## 변경
- 560px 이상 가로 화면: 전장 왼쪽, 상태·조작 오른쪽. 360px 이하 높이에서는 시작 버튼을 전장 하단에 표시하고 전투가 시작되면 숨긴다.
- 화면 투영만 x/y 교환. 적 진행 거리, 사거리, 타깃, 공격 주기, 비용, 저장 좌표는 변경하지 않는다. 배경은 중앙 크롭, 캐릭터와 문자는 똑바로 유지한다.
- 궁수 집중 / 연금술사 광역 / 서리 둔화 / 가시 맹독 / 수호승 가속. 전장 이름표, 선택 설명, 지정 소환의 역할 기호와 효과 설명으로 구별한다. 진화 궁수는 관통 표시.
- 작은 가로 화면에서 자세한 설명은 조작부 상단 영역을 스크롤한다. 버튼은 고정한다.

## 실행
저장소 루트에서 `python3 -m http.server 4180` 실행 후 `/arcade/moonward/` 방문.
화면 자동 회전을 켜고 기기를 돌린다. 세로 화면도 계속 지원한다.

## 검증
- Node 게임 검사 35개 통과. 투영 전후 모든 제단/경로 지점의 거리가 동일함을 검사.
- Chromium UI 검사: 기존 전투, 합성, 진화, 보스, 승패, 저장/복구, 재시작과 함께 568×320, 667×375, 844×390, 915×412, 1024×768 가로 화면 검사.
- 가로/세로 전환 시 같은 정지 상태의 게임 데이터 보존, 44px 조작과 제단 겹침/스크롤 유무, 실제 지정 소환 확인.
- 공유 SW를 수정하지 않고 오프라인 이어하기·나가기, 금융 sentinel 보존 확인.
- 기존 금융 정적 검사, PWA/저장 롤백, 계산 및 finance 검사 통과.
- 전투 수치 변경 없음. 이번 UI 변경에 별도 밸런스 시뮬레이션을 새로 했다고 주장하지 않는다.
- 실제 휴대전화, 설치형 PWA 회전, 터치 감각과 사람의 학습/재미는 미검증. 헤드리스 렌더 시간은 휴대전화 FPS가 아니다.

## Claude 연결 안내
현재 main에는 아케이드 메뉴와 MOONWARD 캐시 연결이 이미 존재한다. 새 파일/의존성/저장 키를 추가하지 않아 메뉴 및 캐시 목록 수정은 필요 없다. 변경 런타임은 `arcade/moonward/{index.html,app.mjs,data.mjs,style.css}` 네 파일이다. 기존 설치 PWA의 배포 반영 정책에 별도 캐시 갱신이 필요하면 금융 담당자가 공유 SW 릴리스 정책에 맞춰 적용한다. 이 작업은 루트 index.html, app.css, sw.js, js/, scripts/, 설정, 다른 게임을 수정하지 않는다.

역할 기호는 직접 작성한 SVG 코드이며 외부 이미지·폰트 의존성을 추가하지 않았다. 기존 게임 아트 출처는 ART.md를 따른다.
