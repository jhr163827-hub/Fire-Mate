## 2. 문제점
1. **같은 앱에서 두 가지 방식**이 섞여 있습니다. 가계부·자산은 `₩1,234,567`, FIRE·은퇴는 `6억 5,000만 원`입니다. 이건 의도된 구분일 수 있습니다(일상 기록과 장기 계획).
2. **1억 이상을 억 없이 표시**하는 곳이 있습니다. 예: 은퇴 비교 기준의 `비교 자산 65,000만 원`, 다음 목표 안내의 `다음 목표 2억까지 21,000만 원`. 바로 옆의 `6억 5,000만 원`과 같은 금액인데 읽기가 어렵습니다.
3. **요약에도 원 단위까지** 나오는 곳이 있습니다. 예: `292만 8,333원`, `-126만 6,667원`. 가정에 기반한 추정치인데 원 단위까지 보이면 실제보다 정확해 보입니다.
4. 단위 입력 혼동: FIRE 입력칸은 `만원` 단위인데, 홈·가계부는 `원` 단위입니다. 입력칸 아래 읽기 도우미가 있어서 지금은 큰 문제는 아닙니다.

## 3. 제안 (추천: A안)

### A안 — 용도별 두 가지 규칙 (추천)
| 용도 | 규칙 | 예 |
| --- | --- | --- |
| 실제 기록 (홈·가계부·거래·자산·소비 분석) | 지금처럼 `₩` + 원 단위 | `₩1,234,567` |
| 계획·추정 (FIRE·은퇴·전략) | `억·만 원`, **만 원에서 반올림** | `6억 5,000만 원`, `293만 원` |
| 1억 이상 | 항상 `억` 사용 | `65,000만 원` → `6억 5,000만 원` |
| 그래프 축·막대 라벨 | 지금처럼 짧게 | `78만` |
| 원 단위까지 필요한 곳 | "자세히 보기" 안의 계산 근거에만 | `292만 8,333원` |

- 장점: 사용자가 이미 익숙한 지금 모습과 가장 가깝고, 바뀌는 범위가 FIRE·은퇴 화면 일부로 작습니다.
- 바뀌는 곳(예상): 은퇴 비교 기준 줄, 다음 목표 안내, 생활비·전략 요약의 원 단위 금액.

### B안 — 모두 `₩` 원 단위
- 모든 화면을 `₩1,234,567`로 통일합니다.
- 단점: `₩650,000,000`처럼 큰 금액은 읽기 어렵고, FIRE 화면 대부분이 바뀝니다.

### C안 — 모두 `억·만 원`
- 가계부·자산까지 `1,234만 5,678원`처럼 바꿉니다.
- 단점: 일상 지출(`₩12,500` → `1만 2,500원`)이 길어지고, 홈·가계부 화면이 크게 바뀝니다.
