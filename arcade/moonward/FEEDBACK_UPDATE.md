# 전투 피드백 개선 · 2026-10-24

사진의 빈 전장 현상은 사용자 요청으로 수정 범위에서 제외했다.

- 준비 상태에 따라 소환 → 추가 소환 → 전투 시작 안내가 바뀐다. 첫 웨이브까지 입구 화살표와 성문 표시를 제공한다.
- 전투 중 다음 웨이브의 실제 적 구성과 방어 보상을 미리 확인할 수 있다. 작전 보기/정비를 열면 시뮬레이션이 멈추며, 부족한 역할을 지정 소환할 수 있다.
- 서리는 결정, 독은 방울, 가속은 이중 화살표로 구별한다. 지원 유닛 선택 시 실제 지원 범위와 연결선을 표시한다. 선택 정보에는 가속을 반영한 공격 간격이 나온다.
- 실제 성문 돌파 시 적 종류별 수·피해·잔여 체력 비율을 기록한다. 가장 많은 성문 피해를 준 종류를 근거로 재도전 힌트를 제공한다. 이것은 패배의 유일한 원인이라는 인과 판정이 아니다.
- 기존 저장 키와 버전은 유지한다. 새 기록은 선택 필드이며 구 저장에 없는 사건은 추정하지 않는다. 재시작 시 기록을 비운다. 피해 통계에서 초과 피해를 제외했지만 실제 전투 피해·비용·확률은 변경하지 않았다.

## 확인한 항목

- Node 엔진/피드백 테스트 17개 통과. 18개 웨이브 예고와 실제 소환 구성 일치, 구 저장 복구, 돌파 기록 저장/중복 방지, 지원 판정 포함.
- Headless Chromium 실제 UI 흐름 18개 검사 통과. 최초 소환, 합성, 정비 중 시간 정지, 지정 소환, 가속 표시, 패배 분석·재도전, 저장 복구, 18웨이브 엔진 완주와 승리 화면 포함.
- 320/360/375/390/430/768px 가로 넘침 없음, 주요 버튼 44px 이상. 작은 화면은 세로 스크롤을 허용한다.
- 100마리 렌더 명령 제출 시간 p95 약 0.6ms(데스크톱 헤드리스). 실기기 FPS 수치가 아니다.
- 실제 공용 SW로 캐시·오프라인 재진입·이어하기 확인. 새 feedback.mjs 포함. 금융 데이터 확인용 키 보존.
- check_app, PWA update, storage rollback, calculations, finance 검사 통과.
- 화면 캡처를 보고 한국어 글꼴·정비 모달·전투 효과를 확인했다. 테스트 환경용 글꼴만 설치했으며 앱 리소스/의존성에 추가하지 않았다.

## 미검증

실제 Android 설치형 PWA, 터치 감각, GPU 성능, 장시간 사람 플레이와 재미/승률은 미검증. 시뮬레이션은 사람 플레이 검증을 대신하지 않는다. 수치 밸런스는 이번 변경 대상이 아니다.

## 실행

저장소 루트에서 `python3 -m http.server 4180` 실행 후 `/arcade/moonward/` 접속.
`node --test arcade/moonward/tests/*.test.mjs`
Playwright 설치 환경에서 `MOONWARD_CHROMIUM=/path/to/chromium node arcade/moonward/tests/browser.cjs` 및 `tests/integration.cjs` 실행.

## Claude 연결 안내

메뉴 경로 변경 없음. 새 런타임 파일은 `arcade/moonward/feedback.mjs` 하나. 기존 arcade 네트워크 우선 런타임 캐시로 수집되며 공용 SW 수정 불필요. 향후 명시적 캐시 목록을 만들 경우 INTEGRATION.md에 적힌 파일 목록에 포함할 것. 금융·기존 게임·공용 설정 변경 없음.
