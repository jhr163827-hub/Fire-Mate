전체 기능 목표는 여러 검증 가능한 PR로 나눈다. v1.6은 아래 첫 단위이며 고용·상점·온라인 기능의 완료를 뜻하지 않는다.

## v1.6.0 첫 단위 · 도감/숙련과 반복 조작

- 기존 요리5종에 장면과 같은 SVG 음식 그림을 선택창·도감에서 재사용. 시간·재료비·접시별/전체 판매액·잠금 조건·완성 기록을 함께 표시한다. 이미지 파일/새 외부 의존성은 추가하지 않는다.
- 조리대 배지는 1분 미만 초, 1시간 미만 분:초로 읽는다. 실제 종료 시각과 비용·총 보상·XP 값은 그대로다.
- 요리사만 직접 그린 양쪽 머리묶음/검은 머리·눈웃음·붉은 상의를 다듬는다. 원본 게임 스프라이트를 확보/복사하거나 공식 라이선스를 확보했다는 주장이 아니다.
- 숙련은 완성 음식을 서빙대로 성공적으로 옮긴 횟수. 자체 기준3회(익숙한 요리)·10회(마스터). 배지는 기록/수집이며 시간·수익 보너스를 주지 않는다. 이 숫자는 원작 값이 아니다.
- 기존 동일 저장 키 아래 `cookbook:{version:1,recipes:[{completed:0},...]}` 를 첫 성공적 이동 때만 추가한다. 기존 완성 횟수는 추정하지 않는다. 루트/도감/각 요리의 미지 필드는 보존한다. recipe 인덱스·조리 중인 ends·기존 코인/판매/XP/시설·배치와 손님은 유지한다.
- 재고 추가·조리대 비우기·숙련 기록은 하나의 기존 transaction에서 저장한다. 실패 때 전부 복원되므로 재시도나 빠른 입력으로 숙련/음식이 중복 지급되지 않는다. 미래 도감 버전은 보존하고 새 조리/이동을 차단한다. 기존 열린 영업의 판매·정산은 도감 필드를 수정하지 않는다.
- 도감은 요리 목록에서 진입하고 뒤로가기로 이전 조리대 목록에 복귀한다. 원래 모달의 영업 일시정지와 초안 없는 조회 흐름을 사용한다.

검증 결과는 해당 PR 본문에 최신 CI·배포 결과와 함께 기록한다. 실제 휴대폰 성능·네이티브 회전·OS 안전 영역, 원작과 같은 속도/애니메이션은 미검증이다.
