### 백업에 새로 넣은 것 (사용자 기록·결정·되돌리기 이력)
- 배열이라 빠지던 것: 여행, 발자국, 홈 표시 설정, 매수 기록 되돌리기, 뱅샐 추가 계좌 기록
- 목록에 없던 사용자 설정·결정: 리밸런싱 목표, 올해 판 해외주식 수익, 적립식 시뮬레이터, 다시 가져오지 않을 거래(`import_deleted`·`import_gone_off`), 다시 자동 분류 안 할 거래(`autocat_skip`), 더치페이 짝·`정산 아님`·전체 끄기, 계획 제안 거절, 오래된 잔고 날짜, 이상 지출 본 것, 켜 둔 예전 자격증 타이머
- 자동 변경 이력(되돌리기용): 중복 결제·카드대금·새 분류·자동 분류·사라진 거래·뱅샐 되돌리기 기록
- 이미 적용한 1회성 정리 표시(없으면 새 폰에서 복원한 기록에 같은 정리가 다시 돔)

### 일부러 뺀 것
- 인증·비밀: 드라이브·Gmail 토큰, Gmail 계정 힌트, Twelve Data 키, ZIP 비밀번호, 앱 잠금(지문 자격 id·비밀번호 해시)
- 이 폰 상태: 마지막 백업 시각, 드라이브 켜짐, 데모 모드, 처음 안내 본 것
- 다시 받는 캐시: 지도, 자격증 목록, 영어 단어, 시세·쿨다운, 거래 압축본(백업엔 전체 거래가 이미 들어감)

## 3. 금융 계산 점검 (이번엔 고치지 않음)

- **[코드] 순자산 vs FIRE 운용자산**: 진행률은 `fireLiquid()`, 표시는 `netAsset()`로 이미 나뉨. 목표별 배정 자금 개념은 아직 없음 → 6-②
- **[코드] 입출금 vs 투자 성과**: 자산 화면 수익률은 매입 원금 대비, 홈 `어제보다`는 순자산 기록 비교(입출금 포함), FIRE `실제 수익률`은 기간 수입·지출을 뺌. 화면마다 기준이 달라 같은 날 숫자가 다름 → 각 숫자 옆 기준 한 줄이 필요
- **[코드] 배당**: 받은 배당(가계부엔 증권사 배당이 안 들어옴 → `dividends.json` × 지금 수량 추정), 예상 배당, 배당 월급 목표가 섞여 보일 수 있음. 연간 결산은 "추정"이라고 씀
- **[코드] 시세·수량·환율 시각**: 시세 시각(`quoteAt`)과 수량 입력 날(`asset_seen`)은 따로 있고, 환율은 시세 응답 시각을 따름. 한 화면에 셋을 같이 보여 주는 곳은 없음
- **[코드] 배당 재투자 중복**: FIRE 계획 수익률은 재투자 포함 가정이라 `.fm-div-reinvest`가 이미 경고함. 배당을 생활비로 쓰는 계산과 동시에 쓰면 중복 위험 → 실험실 화면에서 확인 필요[미검증]
- **[코드] 세금·공제**: 카드 소득공제(15/30/40%, 한도 300만·250만), 해외주식 250만 원 비과세·22%가 코드에 고정. 적용 연도·출처 표시가 없음 → 해마다 바뀌면 틀림. 연도와 "2026년 기준 · 국세청" 같은 근거 줄 필요
- **[코드] 저장된 계획 vs 실험**: `fmPlanNow()`/`fmFirePlanBasis()`와 실험실 입력이 분리되어 있음[실험실 화면 저장 여부 미검증]

## 4. 다음 우선순위 (제안)

1. **데이터 점검 화면** — `내 데이터 보관` 안에 한 화면: 백업에 들어가는 항목·개수, 마지막 파일/드라이브 성공, 사진 수와 연결 안 된 사진, 자동 변경 이력 건수, 원본과 다른 거래(더치페이·중복·취소·분류) 목록. 필요한 데이터: 이미 있음. 범위: 화면 1개 + 집계 함수. 효과: 복원·자동 변경을 사용자가 직접 확인
2. **자동 추정 → 후보 확정** — 중복 결제·결제 취소·사라진 거래 정리도 더치페이처럼 건별 "맞아요/아니에요"와 원본 보존. 필요한 데이터: 각 정리의 백업 키(이미 있음) + `확정` 표시. 다시 가져와도 결정 유지(`import_deleted` 방식)
3. **여행 경비 직접 연결** — 거래 편집에서 여행 고르기/제외(`tx.trip`·`tx.tripOff`), 출장 정산(회사에서 받은 돈)·동행 정산(더치페이 짝 재사용) → `실제 내 부담금`. 이름 추정은 연결이 없을 때만
4. **목표자금 통합 관리** — 기존 자산에 "비상금·여행·버킷·FIRE" 꼬리표로 배정(새 자산 아님, 합계는 순자산을 넘지 못함). 버킷 `saved`·여행 예산·FIRE 운용자산을 한곳에서. 필요한 데이터: 계좌/종목별 배정 비율
5. **자격증 진행 체크리스트** — `합격 → 등록 → 발급 → 갱신` 단계와 날짜(지금 `stage`는 시험 단계만). 응시 조건·일정은 기관 링크만, 확정처럼 쓰지 않음
6. **이번 주 돌아보기** — 할 일 완료·공부 시간·지출·무지출·여행 발자국을 한 장으로(일요일 저녁, 폰 알림 life). 기존 주간 결산(`week_report`)과 합침
7. **업무 영어 문장 복습** — 지금 단어 카드에 `문장` 모드(예문 빈칸 채우기). 데이터: `english-words.json` 예문 재사용
8. **세금·공제 연도 표시**(3절) — 상수에 연도와 출처를 붙이고, 해가 바뀌면 "작년 기준" 경고
