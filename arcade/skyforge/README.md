# SKYFORGE · 비행 공방

FIRE MATE의 독립 비행 슈팅. 한 손 이동·자동 사격·3지선다 성장을 참고한 **창작 게임**이며 탕탕에이스의 그래픽, 캐릭터, 음악, 화면을 복제하지 않았다. 기존 금융 앱과 디펜스 게임은 수정하지 않는다.

## 실행

저장소 루트에서 `python3 -m http.server 4180` 실행 후 `http://localhost:4180/arcade/skyforge/`를 연다. 빌드, 패키지 설치, 외부 CDN이 필요 없다. `file://`는 ES 모듈 때문에 지원하지 않는다.

배포 주소: https://jhr163827-hub.github.io/Fire-Mate/arcade/skyforge/

## 플레이

- 드래그: 상대 이동. 손을 떼면 전투 시간 0.25배. 중앙 흰 점이 피격 판정이다.
- 자동 기관포, 보급 결정 수집, 3개 중 무기 선택. 첫 선택은 전투 시간 8초에 보장한다.
- 무기 8종: 다중 포신 / 관통 광선 / 추적 로켓 / 조준 호위기 / 근접 톱날 / 연쇄 전류 / 감속 파동 / 재충전 장막. 같은 무기 3·6레벨에 형태가 바뀐다. 선택지에는 보유 무기 강화가 최소 하나 포함된다(보유 무기가 모두 최대 레벨이면 제외).
- 전투 하단 장착 무기를 누르면 전투가 멈추고 역할·현재까지의 강화 내용을 볼 수 있다.
- 긴급 펄스: 탄막·위험선 제거, 범위 피해, 잠시 무적. 시작 2회, 최대 3회, 45기 격추마다 1회 충전.
- 3개 배경 지역에 12개 순차 항로. 편대 구성이 시간·항로에 따라 바뀌고, 각 항로 끝에 부채꼴 / 조준 레이저 / 회전 탄막 보스가 나온다. 12개의 전혀 다른 맵이나 보스라는 뜻은 아니다.
- 보스 등장 35초 후 장갑 과열: 받는 피해 3배. HUD와 기체의 발광으로 표시한다. 방어 조합의 지나친 장기전을 줄인다.
- 무피격 3별, 남은 체력 40% 이상 2별, 나머지 클리어 1별. 최고 기록의 증가분만 훈장으로 얻는다. 재도전 중복 지급 없음.
- 4·8탄 클리어로 새 기체. 훈장으로 기관포·장갑·수집 장치를 정비하고 무료로 배분을 초기화할 수 있다. 클리어 결과에서 도전 모드(적 체력 +30%, 초기 편대 추가)를 선택할 수 있다.
- 키보드: 방향키/WASD, Space 펄스, Escape 일시정지. 일시정지 메뉴에서 음소거·효과 축소·재도전·저장 후 나가기를 제공한다.
- 세로를 기본으로 하며 가로에서는 전장 옆에 HUD와 조작 패널을 배치한다. OS 화면 회전을 강제로 잠그는 기능은 없다.

## 파일과 저장

`data.mjs`: 기체, 적, 항로, 무기 설명, 정비/기록 규칙. `engine.mjs`: 고정 60Hz 전투 및 저장 검증. `art.mjs`: 창작 Canvas 비행기·편대·지형·이펙트. `app.mjs`: 화면, 입력, 저장, 오디오. HTML/CSS 포함 런타임 6파일.

게임 전용 localStorage:

- `firemate_skyforge_profile_v1`: 최고 별 기록과 정비
- `firemate_skyforge_run_v1`: RNG·적·탄막·선택지까지 포함한 비행
- `firemate_skyforge_settings_v1`: 소리·효과 축소

2초마다 및 일시정지/페이지 종료 시 저장한다. 재접속은 일시정지 상태로 시작한다. 손상된 비행 저장은 이어하기 대상으로 쓰지 않으며 금융 저장을 읽거나 초기화하지 않는다. 탭 숨김/포커스 이탈 시 정지, pagehide 시 RAF와 오디오 종료, BFCache 복귀 시 정지 상태 복원. 저장 공간 접근 실패는 화면에 알린다.

## 아트·리소스

새로 그린 코드 기반 벡터 아트와 Web Audio 합성음만 사용한다. 외부 이미지·음원·폰트 런타임 의존성이나 라이선스가 필요한 게임 자산이 없다. 색상뿐 아니라 기체 형태, 장비, 발사 패턴으로 역할을 구별한다. 래스터 스프라이트나 상용 수준의 애니메이션 제작물이라고 주장하지 않는다. QA 서버에만 한국어 표시용 Noto Sans CJK를 설치했으며 게임에는 포함하지 않는다.

## 검증

```sh
node --test arcade/skyforge/tests/engine.test.mjs
node arcade/skyforge/tests/simulate.mjs > /tmp/skyforge-simulation.json
# Playwright 및 Chromium은 QA 환경에 별도 설치. 루트 의존성은 변경하지 않는다.
NODE_PATH=/path/to/qa/node_modules SKYFORGE_CHROMIUM=/path/to/chromium \
  node arcade/skyforge/tests/browser.cjs
# 실제 속도의 첫 판 자동 조작을 포함하려면 SKYFORGE_REALTIME=1 추가
```

- 엔진 9개 검증: 시드/이어하기 결정성, 첫 선택, 무기 역할, 펄스와 중복 처치, 패배 상태, 별 보상, 손상 저장, 보스 경고/무적, 과열 피해.
- 브라우저: 실제 포인터 이동/감속, 선택·진화, 저장 복구, 패배/재시작, 승리 보상, 장착 무기 설명, 과열 표시, 320×568 / 390×844 / 430×932 / 844×390 화면 및 44px 펄스 버튼, 금융 키 보존, 기존 루트 SW를 사용한 오프라인 복구.
- 첫 판 실제 속도 자동 포인터 조작: 벽시계 118.6초, 전투 시간 97.3초, Lv.11 도달, 보스 승리. 선택지는 DOM 버튼으로 클릭하고 펄스도 실제 버튼으로 사용했다. 인간 플레이가 아닌 자동 조작이다. 이 측정 이후 보스 과열과 장착 무기 설명을 추가했으며 해당 변경은 별도 브라우저 검증했다.
- 60적/250탄 렌더링 부하: 데스크톱 headless Chromium의 그리기 CPU 시간 p95 약 1.3ms(환경별 차이 있음). 휴대전화 FPS나 GPU 합성 성능 측정이 아니다.
- 기존 금융/PWA 정적·계산·롤백 회귀 검사도 통과했다.

증거: `tests/evidence/`의 화면 캡처와 JSON. `realtime-report.json`은 실제 속도 검증, `browser-report.json`은 최신 회귀 검증이다. 전투/보스/진화 화면 일부는 해당 상황을 재현하기 위한 상태 fixture이며, 실제 속도 완료 화면은 `realtime-result.png`이다.

### 밸런스 조정 근거

12항로 × 3무기 우선순위 × 5시드 = 180회 회피·수집 자동 조작과 1탄 정지 조작 5회를 비교했다. 자동 회피는 미래 탄 위치를 계산하므로 사람보다 훨씬 정확하다. **이 승률을 실제 이용자 승률이나 재미 검증으로 해석하면 안 된다.**

- 첫 선택이 늦어지는 것을 막기 위해 전투 8초 보장.
- 초기 60회 표본에서 강화가 분산되어 진화를 못 본 경우가 있어 보유 무기 선택지 보장 추가. 최종 이동 전략 180회 모두 최소 한 번 진화.
- 전체 항로 확장 검증에서 방어 조합의 최장 전투가 344.5초. 보스 과열 추가 후 같은 시드의 최장 시간이 202.0초로 감소.
- 최종 이동 전략 180/180 클리어, 정지 전략 0/5 클리어. 전투 시간 93.1~202.0초. 균형 조합 평균 107.3초, 기관포 조합 108.7초, 전류/방어 우선 조합 131.1초. 서로 다른 무기로 진행할 수 있지만 공격 조합이 더 빨리 보스를 잡는다.
- 휴대전화 실기기, 터치 피로도, iOS Safari, 장시간 발열, 사람이 느끼는 난이도 및 재플레이 재미, 모든 기체·정비·도전 모드 조합의 통계적 균형은 미검증이다. 실제 사용자 첫 3판의 결과를 보고 추가 조정해야 한다.

## Claude 연결 안내

1. 아케이드 메뉴에 제목 `SKYFORGE · 비행 공방`, 설명 `한 손 회피 · 무기 진화 · 12개 항로`, 링크 `./skyforge/`를 추가하면 된다. 금융 홈에는 넣지 않는다. 이 PR에서는 공용 메뉴 파일을 수정하지 않았다.
2. 기존 `sw.js`의 `/arcade/` 네트워크 우선 런타임 캐시가 `.mjs`까지 저장한다. 이미 FIRE MATE 루트 SW가 설치된 환경에서는 게임을 한 번 온라인으로 열면 오프라인 이어하기가 작동함을 검증했다. 신규 독립 방문자는 루트 SW가 없을 수 있으므로 오프라인 동작을 보장하지 않는다.
3. 게임 코드/리소스를 금융 초기 로딩에 import하거나 ASSETS에 선로딩할 필요 없다. 반드시 메뉴를 통해 진입할 때 로드한다. 미리 오프라인 제공하려는 별도 제품 결정이 있다면 게임 경로 6개를 캐시하되 사용자 진입 시에만 수행한다.
4. 금융의 BUILD/VERSION/캐시 버전은 변경하지 않았다. 게임 전용 키를 금융 키로 합치거나 재사용하지 않는다.
