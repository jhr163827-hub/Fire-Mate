# 월광 수호단 / MOONWARD v1.0

FIRE MATE용 독립 랜덤 디펜스. 한 맵, 5종 수호자, 3등급, 18웨이브(6·12·18 보스). 자동 전략의 완주 시간은 1배속 기준 약 12~13분이며, 사람이 선택 창을 여는 시간은 별도다.

## 실행

저장소 루트에서 `python -m http.server 4180`을 실행하고 브라우저에서 `http://localhost:4180/arcade/moonward/`를 연다. ES 모듈을 사용하므로 파일을 `file://`로 직접 열면 안 된다. 런타임 외부 CDN·라이브러리·API·빌드 단계는 없다. 게임에 진입할 때만 약 0.5MB의 게임 코드와 아트가 로드된다(검증 스크린샷 제외).

아케이드 메뉴의 **월광 수호단** 카드로 진입한다. FIRE MATE에서는 설정 → 게임 아케이드로 이동할 수 있다. 메뉴·캐시 통합 결과는 [INTEGRATION.md](INTEGRATION.md) 참조.

## 플레이

- 빈 제단을 누르고 랜덤 소환(50 조각) 또는 지정 소환(85 조각).
- 첫 랜덤 소환은 1성 궁수. 랜덤 소환은 4% 확률로 2성. 11회 연속 2성이 없으면 다음 랜덤 소환은 2성 보장. 지정 소환은 항상 1성.
- 랜덤 소환 네 번째마다 현재 없는 역할을 우선한다. 지정 소환은 이 보장 주기에 포함되지 않는다.
- 같은 종류·등급 2명 + 15 조각 → 같은 종류의 다음 등급. 결과와 소비할 재료를 확인한 뒤 확정한다. 선택한 제단에 남는다.
- 2성을 만들면 공격력·독 피해 2.55배. 사거리·둔화·가속은 늘어나지 않는다. 최고 3성.
- 이동은 빈 제단으로 이동하거나 다른 수호자와 자리를 교환한다. 판매는 확인 후 원가 일부를 반환한다.
- 성문 생명 20. 일반 적 누출 −1, 보스 −5. 보스가 통과해도 생명이 남으면 다음 웨이브로 진행한다.
- 적 처치와 웨이브 보상으로 재화를 얻는다. 전투가 끝나면 7초 정비 시간 후 다음 웨이브가 시작된다.
- 설정: 일시정지, 1×/2×, 효과음, 효과 줄이기, 새 판, 저장하고 나가기.

### 역할

| 수호자 | 역할 | 타깃·상호작용 |
| --- | --- | --- |
| 달빛 궁수 | 빠른 단일 공격 | 선두 우선. 갑각·보스에게 피해 40% 감소 |
| 잿불 연금술사 | 광역 공격 | 선두와 반경 45 안의 적을 함께 공격 |
| 서리 마녀 | 둔화 | 아직 둔화되지 않은 적 우선. 3초, 일반 적 48%·보스 24% 감소 |
| 가시 사냥꾼 | 지속 피해 | 중독되지 않은 강한 적 우선. 4초 지속, 가장 강한 활성 독으로 갱신 |
| 별종 수호승 | 공격 가속 | 반경 107의 다른 수호자 공격속도 +25%, 중첩 불가 |

## 코드 구조

- `data.mjs`: 수치, 소환 비용, 웨이브, 경로, 배치 좌표.
- `engine.mjs`: DOM·오디오와 분리된 30Hz 고정 스텝 엔진, 시드 RNG, 검증된 저장 복구.
- `app.mjs`: 입력, 렌더링, 오디오, 대화상자, 저장, 수명주기.
- `art.mjs`, `art/`: 실제 작은 표시 크기에 맞춘 아트 로딩.
- `tests/`: 엔진 회귀, 다중 시드 전략 시뮬레이션, 브라우저 조작과 화면 검증.

저장 키는 `firemate_moonward_v1` 하나만 사용한다. 금융 저장 키를 열거나 변경하지 않는다. 저장은 소환·합성·판매 등 주요 동작, 4초 간격, 화면 숨김·종료 시 수행한다. 불러오기 확인창을 닫기 전에 재새로고침해도 기존 진행을 덮어쓰지 않는다. 브라우저 저장이 차단되면 화면에 알리고 메모리에서 계속 플레이한다. 재화·통계·옵션·최고 도달 웨이브는 이 기기에만 저장된다. 서버나 계정 동기화는 없다.

이미지는 정적 스프라이트이며 대기 움직임, 공격 반동, 피격 이펙트, 소멸 파티클로 애니메이션을 구성한다. 다방향 프레임 애니메이션·성우·배경 음악은 구현하지 않았다. 효과음은 Web Audio 합성이다.

## 검증

```sh
node --test arcade/moonward/tests/engine.test.mjs
node arcade/moonward/tests/simulate.mjs
node arcade/moonward/tests/browser.cjs
node arcade/moonward/tests/integration.cjs
```

브라우저 검증에는 환경에 설치된 `playwright`와 Chromium이 필요하다. 공용 package.json이나 의존성은 수정하지 않았다. 브라우저 바이너리를 지정할 때는 `MOONWARD_CHROMIUM=/path/to/chromium`, 결과 경로는 `MOONWARD_EVIDENCE=/path/to/evidence`로 설정한다. 테스트 서버는 스크립트 안에서만 열리고 끝나면 닫힌다.
