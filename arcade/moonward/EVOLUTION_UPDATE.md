# 최종 진화 · 2026-10-24

3성 궁수·잿불을 선택하면 기존 합성 버튼이 '진화 · 200'으로 바뀐다. 비용이 부족해도 미리보기를 열어 외형·효과·부족한 재화를 확인할 수 있고, 확정은 충분한 재화가 있을 때만 가능하다. 수호자를 소비하지 않고 위치·기존 축복·공격 대기시간을 유지한다. 판매 환급은 기존 3성과 같으며 진화 비용을 반환하지 않는다.

- 월광 관통궁: 실제 사거리 안에서 여러 적이 겹치는 직선을 조준한다. 가까운 적부터 최대 3명, 첫 적 100% / 추가 적 40% 피해. 갑각 저항·서리 추격은 각 적에게 적용한다. 시각적 화살과 명중 계산은 같은 시작점·끝점을 사용한다.
- 잔불 연금술사: 원래 폭발에 더해 착탄 지점 반경 32에 2.4초 동안 초당 24 피해. 수호자마다 최근 지대 하나만 남기며 겹쳐도 피해를 더하지 않는다. 이동시 기존 지대는 남은 시간 동안 유지, 판매·웨이브 종료·승패·재시작에서는 해당 지대를 정리한다.
- 공격력·속도·사거리와 기존 합성·보스 축복 규칙은 유지한다. 진화 전용 원본 그림 2종, 관통 화살, 잔불 불꽃, 진화 연출을 추가했다. 효과 줄이기에서는 불꽃의 흔들림을 멈춘다.

## 저장·안정성

`firemate_moonward_v1` 유지. 유닛의 선택적 `evolved` 필드와 상태의 선택적 `fields` 배열을 추가했다. 구 저장은 진화 없음/잔불 없음으로 이어간다. 진화 종류·등급·지대 소유자·지속시간·중복 소유자 등을 검증한다. 잔불 피해와 만료는 고정 시뮬레이션 단계로 계산해서 1×/2×와 저장 복구에 같은 결과를 낸다. 진화 연속 확정으로 중복 차감되지 않는다.

- 브라우저 UI 흐름 20개 통과. 두 진화의 미리보기, 부족한 재화, 취소, 중복 확정, 진화 공격, 잔불 있는 상태 재접속, 판매/재시작 포함. 기존 합성·보스 축복·18웨이브 완주·승패도 유지.

## 밸런스 가설 및 비교

처음부터 단일 보스 피해를 크게 올리기보다 밀집 처리와 지형 활용에 집중했다. 비용 200은 랜덤 소환 4회와 같고, 추가 관통 피해는 40%, 잔불은 중첩 금지로 한정했다. 초기 수치로 아래 320판을 비교한 결과, 혼합 조합은 강화되지만 단일 종류만 진화시키는 전략은 성공하지 못했다. 이번 표본에서는 수치를 추가 변경하지 않았다.

각 행은 시드 1~20 고정. 진화 정책은 병력이 8명 이상이고 해당 3성이 있으면 구매를 잠시 멈추고 200을 모아 진화한다. 보스 보상은 동일하게 보급을 선택한다.

| 구매 전략 | 진화 안 함 | 궁수만 진화 | 잿불만 진화 | 둘 다 진화 |
|---|---:|---:|---:|---:|
| 역할 혼합 | 15/20 | 18/20 | 16/20 | 18/20 |
| 무작위 소환·합성 | 10/20 | 19/20 | 16/20 | 19/20 |
| 궁수만 | 0/20 | 0/20 | 0/20 | 0/20 |
| 잿불만 | 0/20 | 0/20 | 0/20 | 0/20 |

단일 종류 정책은 진화를 위해 저축하면서 오히려 도달 웨이브가 낮아졌다. 진화 우선순위는 무조건 정답이 아니다. 관통 진화가 이 단순 정책들에서는 더 유리하며, 사람의 승률·재미·완전한 균형 검증으로 해석하지 않는다. 시드별 승패·도달 웨이브·남은 재화·최초 진화 웨이브는 `tests/evidence/evolution-simulation.json`에 있다.

저장소 루트 `python3 -m http.server 4180` 후 `/arcade/moonward/`.

새 런타임 파일: `evolution.mjs`, `art/archer-evolved.webp`, `art/ember-evolved.webp`. 기존 아케이드 런타임 캐시가 게임 진입 때 수집한다. 메뉴·공용 SW·의존성 변경 없음. 명시적 캐시 목록을 나중에 만들면 INTEGRATION.md의 목록을 사용한다.

실기기 설치형 PWA·터치 감각·장시간 사람 플레이는 미검증. 스크린샷은 검증용 전투 상태에서 실제 UI를 캡처했다. 외형은 내장 imagegen으로 만들었고 최종 파일 위치·정확한 프롬프트는 ART.md에 기록했다. 보스 패턴 차별화는 이번 범위에 포함하지 않는다.
