진화 PR #140 → 보스 PR #144 다음에 적용하는 도감 개선이다. 새 브랜치에서 게임 전용 파일만 수정한다. 병합·배포는 이번 작업에 포함하지 않는다. 먼저 두 선행 PR을 순서대로 반영한 뒤 이 후속 PR의 base를 main으로 바꾸고 CI를 확인한다.

## 사용자 흐름

하단 **수호자 도감 → 진화 조합 → 관통궁/잔불 조합**에서 3성을 얻기 전부터 진화 전후 외형, 공격 방식, 조합 재료, 현재 병력 기준 남은 비용을 확인한다. **수호자·규칙**에는 기존 5개 역할·랜덤 보장·합성·승리 조건을 유지한다.

- 1성 4명 → 2성 2명 → 3성 1명 → 진화 경로를 표시한다.
- 같은 종류의 보유 1/2/3성만 계산한다. 이미 있는 2/3성을 우선 활용하는 합성 횟수를 안내하며 다른 종류는 재료로 계산하지 않는다.
- 비용은 **부족한 1성을 85조각 지정 소환으로 채우는 기준**이다. 랜덤 소환의 비용/결과를 확정값처럼 제시하지 않는다.
- 예: 2성 궁수 1명 + 1성 1명 → 1성 1명 추가(85) + 합성 2회(30) + 진화(200) = 앞으로 315조각. 보유 180이면 부족 135.
- 유닛이 전혀 없으면 585조각, 2성 2명이면 215조각, 3성 1명이면 진화 200조각만 필요하다. 진화 완료 시 완료 상태를 표시한다.
- 서리·지원과의 조합, 직선/밀집 구간의 배치 의도를 설명한다. 제단이 가득 찼는데 재료가 부족하면 공간 확보를 안내한다.
- **보유 수호자 선택**은 병력을 선택만 한다. 3성이 준비됐다면 기존 진화 미리보기로 이어지고, 재화가 충분해야 별도 확정 버튼을 누를 수 있다. 도감 열기·종류 변경·선택만으로 소환/합성/진화/재화 차감이 일어나지 않는다.
- 도감을 읽는 동안 전투 정지. 작은 화면과 가로 화면에서도 분류 버튼·돌아가기 버튼을 유지하고 내용 영역만 스크롤한다.

패배 원인 안내는 기존 `debrief()`의 실제 돌파 기록을 유지했다. 비슷한 결과 화면이나 추가 성장 메뉴를 만들지 않았다.
